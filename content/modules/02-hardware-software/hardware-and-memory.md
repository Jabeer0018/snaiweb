## Hardware

> [!IMPORTANT]
> **Hardware** = the physical parts of a computer — the things you can see and touch.

Core numbered examples: 1. Monitor, 2. Keyboard & Mouse, 3. CPU, 4. RAM, 5. Hard Disk, 6. Printer.

### Five Hardware Sub-Categories

- **Input Devices:** Send data/commands to a computer (Keyboard, Mouse, Mic, Digital Pen, Webcam, Touchscreen, Scanner, Game controller).
- **Output Devices:** Show results/feedback (Monitor, Headset without Mic, Speaker, Projector, Printer).
- **Storage Devices:** HDD, SSD, Memory card.
- **Compute Devices:** CPU, GPU.
- **Internal Components:** RAM, Motherboard, Cooling Fan.

## CPU vs. GPU

| Feature | CPU (Central Processing Unit) | GPU (Graphics Processing Unit) |
| --- | --- | --- |
| **Role** | Brain of the computer — general tasks and decision-making | Specialized processor for graphics and parallel tasks |
| **Cores** | Few, powerful cores | Thousands of smaller cores |
| **Best for** | General tasks and decision-making | Gaming, video editing, 3D modeling, VR, and AI |

## Primary Memory (RAM) vs. Secondary Storage

- **Primary Memory (RAM):** Temporary, high-speed working memory directly accessed by the CPU for running programs. It is **volatile** (cleared when power turns off).
  - *Trick question:* Is RAM permanent storage? **No** — RAM is temporary memory; photos/files stay safe on secondary storage.
- **Secondary Storage:** Long-term storage that keeps data when power is off.

| HDD (Hard Disk Drive) | SSD (Solid State Drive) |
| --- | --- |
| Uses magnetic disks to store data | Uses flash memory (no moving parts) |
| Has moving parts (spinning platters, read/write heads) | Much faster than HDD in reading and writing data |
