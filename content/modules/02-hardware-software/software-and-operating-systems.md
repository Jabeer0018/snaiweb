## Software

> [!IMPORTANT]
> **Software** = a set of instructions or programs that tell the computer what to do and how to perform tasks. Without software, hardware is useless.

**Flow:** `Input -> Software -> Hardware -> Output`

### Two Main Types of Software

| System Software | Application Software |
| --- | --- |
| Controls & manages hardware and system resources while providing a platform for apps to run. | Allows users to perform useful tasks; relies on system software to access hardware. |
| **Examples:** Operating Systems, Device Drivers, Compilers, System Utilities. | **Examples:** Media Players, Browsers, Databases, Games, Office Tools, Spotify. |

## Operating Systems (OS)

The OS is the first software you interact with; it mediates between you and the hardware.

- **macOS:** Runs on MacBooks; tight integration with Apple hardware.
- **GNU/Linux:** Open-source OS used on laptops, servers, cloud systems, and supercomputers.
- **Microsoft Windows:** Most widely used desktop OS globally across homes, schools, and enterprises.
- **Android:** Mobile OS for smartphones and tablets focused on touch, portability, and battery efficiency.

### Windows vs. macOS vs. Linux

| Feature | Windows | macOS | Linux |
| --- | --- | --- | --- |
| **Ease of Use** | User-friendly; low-to-moderate learning curve | Extremely user-friendly; very low learning curve | Requires technical knowledge; moderate-to-high curve |
| **Customization** | Limited but accessible | Minimal, controlled by Apple | Highly customizable, DIY-friendly |
| **Compatibility** | Wide app & hardware support | Limited to Apple ecosystem | Extensive range, requires tuning |
| **Security** | Moderate, regular updates | High security, minimal maintenance | High security, user-managed |
| **Target Users** | Everyday & business users | Professionals, creatives | Tech enthusiasts, developers |

### Same Hardware, Different Experience (Ubuntu Demo)

Running Ubuntu Linux on the same hardware shows familiar elements (desktop, windows, file manager, web browser) alongside key differences: the **Terminal** is far more central, the interface differs, and software is installed via **package managers** rather than an app store.
