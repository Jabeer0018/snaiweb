## Questions This Course Answers

- What actually happens when you run a program?
- Where are your files really stored, and what are file permissions?
- How do developers work in a terminal using CLI tools?
- How do developers collaborate on platforms like GitHub?
- What is AI actually doing when it generates an answer?
- How should engineers use AI while learning and building?

## The Journey — Three Acts

1. **Act 1 — Know your System ("Know the Machine"):** Hardware, terminal, OS, how software runs, Git, and networks.
2. **Act 2 — Understand AI ("Know the Other Machine"):** What AI is, how it works, and how to work with it.
3. **Act 3 — Use Both Together:** Combine both to explore real projects, learn new tech, and verify AI instead of blindly trusting it.
