- **Computer vs. Juicer:** Computers can be **reprogrammed** to run different programs; a juicer performs one fixed task.
- **CPU vs. GPU:** CPU has few, fast cores for sequential tasks; GPU has thousands of smaller cores for parallel tasks (graphics, AI).
- **RAM vs. Secondary Storage:** RAM is **volatile** working memory; SSD/HDD is permanent storage.
- **Compiler vs. Interpreter:** Compiler (C, 1972) translates the whole program **before** running; Interpreter (Python, 1989) translates **line by line while** running.
- **Hub vs. Switch vs. Router:** Hub broadcasts to all; Switch sends to intended device via **MAC**; Router connects networks via **IP**.
- **LAN < MAN < WAN:** Local area (home/office) < City/campus < Global/long-distance.
- **Coding 1.0 vs. Coding 2.0:** Coding 1.0 = human writes the step-by-step procedure; Coding 2.0 = human supplies data, **data becomes the program**.
